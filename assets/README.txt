輝度スケジューラ
================

指定した時刻にディスプレイの明るさを自動で変えるアプリです。
「昼は明るく、夜は暗く」のように、毎日決まった時刻に明るさが変わります。


■ 動作環境

  Windows 10 / Windows 11
  （追加のインストールは不要です）

  明るさを変えられるディスプレイ
    ・外付けモニター: DDC/CI に対応したもの
      モニターの設定（本体のボタンで開くメニュー）で DDC/CI がオフになっていると
      変更できません。
    ・ノート PC の内蔵画面
    ・HDR がオンのモニター（下の「HDR のモニターについて」を参照）


■ はじめかた

  1. ZIP を右クリック →「すべて展開」で、好きな場所に展開します。
     （例: ドキュメント\BrightnessScheduler）
  2. BrightnessScheduler.exe をダブルクリックして起動します。
  3. 設定画面の「追加」から、時刻と明るさ（0〜100%）を登録します。

  変更はその場で保存・反映されます。
  画面を閉じても、アプリはタスクトレイ（画面右下）で動き続けます。


■ 初回起動時に「Windows によって PC が保護されました」と表示されたら

  インターネットから入手した、署名のないアプリで表示される確認画面です。
  「詳細情報」をクリックし、「実行」を押すと起動できます。


■ 変化の仕方

  時刻ごとに、次の 2 つから選べます。

    ・その時刻に切り替え … 時刻になったら、その明るさにすぐ変えます。
    ・なめらかに変化     … 前の時刻からゆっくり変え始め、その時刻にちょうど
                           その明るさになるように、少しずつ変えます。

  画面上部のグラフで、24 時間の明るさの変化を確認できます。


■ 一時的に暗くする

  目が疲れたときなど、スケジュールに関係なく、しばらく画面を暗くできます。
  設定画面の上部の「一時的に暗くする」、またはタスクトレイのアイコンを右クリック →
  「一時的に暗くする」から、時間を選びます。

    ・30 分 / 1 時間 / 2 時間 … 時間が来たら、自動でスケジュールの明るさに戻ります。
    ・元に戻すまで            … 「元の明るさに戻す」を押すまで暗いままです。

  暗さは、今の明るさの「少し暗く（3/4）」「半分に」「かなり暗く（1/4）」から選べます
  （同じメニューで切り替えます）。途中で戻すときは「元の明るさに戻す」を押します。


■ モニターごとの補正

  同じ明るさでもモニターによって見え方が違うときは、設定画面右下の
  「モニターごとの補正」で、モニターごとに実際に設定する値を調整できます。

    ・範囲で指定 … 0% のとき・100% のときの値を決めます（例: 10〜70%）
    ・ずらす     … どの明るさでも同じだけ足す・引きます（例: −15%）
    ・倍率       … 掛けます（例: 70%）

  「範囲で指定」は「ガイドで合わせる」を押すと、手順に沿って合わせられます。


■ HDR のモニターについて

  HDR がオンのあいだは、多くのモニターで本体の明るさを変えても表示に反映されません。
  そのため HDR がオンのモニターでは、Windows の
  「設定 → システム → ディスプレイ → HDR → SDR コンテンツの明るさ」を変えます。

  ・変わるのはデスクトップやふつうのアプリの明るさです。
    HDR の動画やゲームの明るさは変わりません。
  ・Windows の設定そのものを書き換えるため、アプリを終了・削除しても、
    最後に設定した値のままになります。
  ・Windows の設定を変えられたくない場合は、設定画面の
    「HDR のモニターも変える」をオフにしてください。
  ・この機能は Windows の設定画面と同じ仕組みを使っていますが、Microsoft が
    公開していない機能のため、Windows の更新で使えなくなる可能性があります。
    その場合は通知でお知らせします。


■ 使い方のヒント

  ・タスクトレイのアイコンをクリックすると設定画面が開きます。
  ・右クリックで「今すぐ適用」「明るさの自動変更（オン/オフ）」「一時的に暗くする」
    「終了」が選べます。
  ・モニター本体のボタンで明るさを変えた場合は、「今すぐ適用」でスケジュールの
    明るさに戻せます。
  ・最初の時刻より前（深夜など）は、前日の最後の明るさになります。
  ・「Windows の起動時に開始」をオンにすると、PC の起動時に自動で動き始めます。
    このときは画面を出さずに、タスクトレイで静かに動きます。
  ・exe を別の場所に移動した場合は、新しい場所の exe を一度起動してください。
    自動起動の登録先が自動で新しい場所に更新されます。


■ 新しいバージョンに更新するときは

  タスクトレイのアイコンを右クリック →「終了」してから、今使っているフォルダーの
  BrightnessScheduler.exe を新しい exe で上書きしてください。設定も自動起動もそのまま引き継がれます。

  新しいバージョンを別のフォルダーに展開した場合は、自動起動が古い exe を指したままになります。
  新しい exe を起動して、設定画面の「Windows の起動時に開始」のスイッチを
  一度オフにしてから、もう一度オンにしてください。そのあと古いフォルダーは削除して構いません。


■ 明るさが変わらないときは

  ・モニターの設定（本体のボタンで開くメニュー）で、DDC/CI がオンになっているか
    確認してください。
  ・設定画面の下に「対象: 〜」と、明るさを変えるモニターの名前が表示されます。
    表示されていないモニターは、このアプリからは変更できません。


■ PC を起動しても自動で立ち上がらないときは

  Windows の設定で、自動起動がオフになっていることがあります。
  その場合は、アプリの設定画面に「Windows の設定で自動起動がオフになっています」と
  表示されます。次のどちらかで、オンに戻してください。

    ・アプリの設定画面で「Windows の起動時に開始」のスイッチをオンにする
    ・Windows の 設定 → アプリ → スタートアップ で「輝度スケジューラ」をオンにする


■ タスクトレイにアイコンが見当たらないときは

  Windows 11 では、新しいアプリのアイコンは最初、タスクバー右側の「^」の中に
  隠れています。常に表示するには、次のように設定します。

    1. タスクバーの何もないところを右クリック →「タスクバーの設定」
    2. 「その他のシステム トレイ アイコン」を開く
    3. 「輝度スケジューラ」をオンにする

  （Windows 10 の場合は「タスク バーに表示するアイコンを選択します」から設定します）

■ アンインストール

  1. 設定画面で「Windows の起動時に開始」をオフにします。
  2. タスクトレイのアイコンを右クリック →「終了」を選びます。
  3. 展開したフォルダーを削除します。
  4. 設定も消す場合は、次のフォルダーを削除します。
       %APPDATA%\BrightnessScheduler
     （エクスプローラーのアドレス欄に貼り付けると開けます）

  インストーラーは使っていないため、手順 1 で自動起動をオフにしておけば
  アプリの痕跡は残りません（ディスプレイの明るさと、HDR のモニターの
  「SDR コンテンツの明るさ」は、最後に設定されたまま残ります）。
