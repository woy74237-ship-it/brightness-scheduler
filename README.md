# 輝度スケジューラ

指定した時刻にディスプレイの明るさを自動で変えるタスクトレイ常駐アプリです（[壁紙スケジューラ](https://github.com/woy74237-ship-it/wallpaper-scheduler) の明るさ版）。

## 使い方

1. `BrightnessScheduler.exe` を起動（初回は設定画面が開きます）
2. 「追加」で時刻・明るさ（0〜100%）・変化の仕方を登録

変更はその場で保存・反映されます。

- **その時刻に切り替え**: 時刻になったら、その明るさにすぐ変えます。
- **なめらかに変化**: 前の時刻から少しずつ変えて、その時刻にちょうどその明るさにします（例: 18:00 に 60%、22:00 に 30%（なめらか）なら、20:00 には 45%）。
- 明るさはつながっているすべてのモニターに同じ値で設定します（各モニターの最大値に対する割合）。
- 画面上部のグラフで、24 時間の明るさの変化を確認できます。
- モニター本体のボタンで明るさを変えた場合は、「今すぐ適用」でスケジュールの明るさに戻せます。
- スリープからの復帰・ロック解除・モニターの接続時には、少し待ってから設定し直します。

### 対応しているモニター

- **外付けモニター**: DDC/CI に対応したもの。モニターの設定（OSD メニュー）で DDC/CI がオフになっていると変更できません。
- **ノート PC の内蔵画面**: Windows の明るさ設定（WMI）で変更します。

## ビルド

追加のインストールは不要です（Windows 標準の .NET Framework 4.x の `csc.exe` を使用）。

```powershell
.\build.ps1
```

`bin\BrightnessScheduler.exe` が生成されます。

アイコンのデザインを変えたときは `tools/MakeIcon.cs` を編集し、`.\tools\make-icon.ps1` で `assets/app.ico` を再生成します。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `src/Core.cs` | バージョン・設定の保存・スケジュール計算・自動起動 |
| `src/Display.cs` | モニターの明るさの読み書き（DDC/CI・WMI）と専用スレッド |
| `src/App.cs` | タスクトレイ常駐部とエントリポイント |
| `src/MainForm.cs` | メイン画面 |
| `src/EntryDialog.cs` | 追加・編集ダイアログ |
| `src/BrightnessControls.cs` | グラフ・カード・スライダーなど |
| `src/Controls.cs` / `Dialogs.cs` / `Theme.cs` | 壁紙スケジューラと共通の部品・配色 |

設定は `%APPDATA%\BrightnessScheduler\settings.json` に保存されます。
