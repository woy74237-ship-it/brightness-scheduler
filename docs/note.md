タイトル：
夜になると画面がまぶしい…を解決！明るさが時刻で自動で変わる無料の Windows アプリ「輝度スケジューラ」を作りました

---

昼間はちょうどよかったモニターの明るさが、夜になるとやけにまぶしく感じる。
かといって、毎晩モニターのボタンを押して暗くするのは面倒……。

そんな悩みを解決するために、**決めた時刻にディスプレイの明るさを自動で変えるアプリ**を作りました。無料で使えます。

［画像：docs/images/main.png］
朝は 80%、お昼は 100%、夜 22 時に向けてゆっくり 30% まで暗くなる設定。今の明るさと、一日の変化がひと目でわかります。

## どんなアプリ？

「朝 7 時は 80%」「夜 22 時は 30%」のように、**時刻と明るさを登録しておくだけ**で、毎日その時刻にモニターの明るさが変わります。

パソコンのモニターの明るさは、ふつうはモニター本体のボタンで変えます。メニューを開いて、何度もボタンを押して……と手間がかかるので、つい明るいまま使ってしまいがちです。このアプリなら、一度設定すれば、あとは毎日自動です。

## できること

・時刻を決めて、明るさを自動で変える（毎日くり返し）
・その時刻にパッと変えるか、ゆっくり変えていくかを選べる
・一日の明るさの変化を、グラフでひと目で確認
・外付けモニターと、ノート PC の画面に対応
・HDR をオンにしているモニターにも対応
・2 台のモニターで見え方が違うときは、モニターごとに補正できる
・パソコンを起動すると、自動で動き始める（オン／オフできます）

## 夜に向けて、ゆっくり暗く

明るさの変え方は 2 種類から選べます。

・**その時刻に切り替え**：時刻になったら、すぐその明るさに
・**なめらかに変化**：前の時刻からゆっくり変えて、その時刻にちょうどその明るさに

おすすめは「なめらかに変化」です。たとえば「12 時に 100%、22 時に 30%（なめらか）」にしておくと、午後から夜にかけて、気づかないうちに少しずつ暗くなっていきます。急に暗くならないので、作業のじゃまになりません。

［画像：docs/images/edit.png］
明るさはスライダーで選びます。動かすとその場で画面の明るさが変わるので、実際に見ながら決められます。

## 2 台のモニターの明るさをそろえる

モニターを 2 台使っていると、同じ「50%」でも片方だけ明るく見える、ということがよくあります。メーカーや種類（液晶・有機 EL など）によって、明るさの感じ方が違うためです。

そこで、**モニターごとに明るさを補正する機能**を付けました。

［画像：docs/images/correction.png］

補正の方法は 3 つから選べます。

・**範囲で指定**：「0% のときは 12%、100% のときは 78%」のように決める
・**ずらす**：いつも 10% 暗くする、のように一律でずらす
・**倍率**：明るさを 7 割にする、のように掛ける

いちばんきれいに合わせられるのは「範囲で指定」です。「ガイドで合わせる」を押すと、

1. 画面が暗い状態になるので、もう 1 台と同じ暗さに見えるまでスライダーを動かす
2. 画面が明るい状態になるので、同じ明るさに見えるまでスライダーを動かす

の 2 ステップで、実際の画面を見比べながら合わせられます。その間の明るさは、自動でそろいます。

## HDR のモニターにも対応

HDR をオンにしているモニターは、モニター本体の明るさを変えても、画面の明るさが変わらないことがほとんどです。

そこでこのアプリでは、HDR がオンのモニターについては、Windows の設定にある「SDR コンテンツの明るさ」を変えて調整します。デスクトップやブラウザなど、ふだんの画面の明るさが変わります（HDR の動画やゲームの明るさは変わりません）。

Windows の設定を変えてほしくない場合は、「HDR のモニターも変える」をオフにすれば、HDR のモニターには何もしません。

## 使い方はかんたん 3 ステップ

1. ダウンロードした ZIP を展開して、「BrightnessScheduler.exe」をダブルクリック
2. 「追加」ボタンを押して、時刻と明るさを選ぶ
3. あとは放っておくだけ！

モニターの明るさが変わらないときは、モニター本体の設定メニューで「DDC/CI」という項目がオンになっているか確認してください。多くのモニターは最初からオンになっています。

## 安心して使えるように

・**インストール不要**：ZIP を展開するだけです
・**インターネットに接続しません**：設定がどこかに送られることはありません
・**ソースコードを公開**：中身はすべて GitHub で確認できます

初めて起動するときに「Windows によって PC が保護されました」という画面が出ることがあります。これは、個人で作ったアプリに表示される確認画面です。「詳細情報」を押してから「実行」を押すと起動できます。

使うのをやめるときは、設定画面で「Windows の起動時に開始」をオフにしてアプリを終了し、フォルダーごと削除すれば OK です。
